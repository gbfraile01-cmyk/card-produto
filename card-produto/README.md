# CardProduto com Styled Components

Exercício de CSS-in-JS: componente `CardProduto` (nome, preço e botão "Adicionar ao carrinho") estilizado inteiramente com **Styled Components**.

O botão muda de cor conforme a prop booleana `adicionado`:

- `true` → verde `#198754`
- `false` → cinza `#6c757d`

## Como rodar

```bash
npm install
npm run dev
```

## Tecnologias

React 18, Vite, Styled Components 6
